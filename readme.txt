１．概要 
これは、Microsoft Edge上で動作する拡張機能です。
ラグナロクオンライン（RO）公式の「クエスト連動」機能を利用するもので、
ブラウザから参照できるキャラクター（達）のクエスト情報取得、
まとめてCSVとして保存する機能を提供します。
 
２．インストール方法 
1. ダウンロードしたZIPファイルを、パソコン上の任意の場所に解凍してください。
2. Microsoft Edgeを開き、アドレスバーに「edge://extensions/」と入力して
　Enterを押します
（または、右上のメニュー「…」＞「拡張機能」＞「拡張機能の管理」を開きます）
3. 画面左下（または左メニュー）にある「開発者モード」のスイッチを【オン】にします。
4. 管理画面上方に表示される「展開して読み込み」ボタンをクリックします。
5. 上の手順で「解凍したフォルダ」を選択します。
6. ブラウザのURLバーの右側、拡張機能ツールに本拡張機能のアイコンが追加
 されれば準備完了です。
 
３．使用方法 
1. Edgeブラウザ上で、ラグナロクオンライン公式サイト
　　(https://ragnarokonline.gungho.jp/) を開き、自分のアカウントに
　ログインします。
2. 画面内 [クエスト連動] を押して「クエスト情報」画面に移動します。
3. クエスト情報画面で、任意のワールドを選択します。
　この時点で、ブラウザのURL表示が以下の形式になっていることを確認してください。
　https://rowebtool.gungho.jp/quest/xx/yy
　（xxはサーバに連動した数値、yyは現在表示されているキャラに対応しています）
4. この画面を開いた状態のまま、Edge右上の「拡張機能」から本拡張機能を
　起動してください。ポップアップ画面が表示されます。
5．ポップアップ画面に表示されている「保存を開始する」ボタンを押してください。~
するとクエスト情報画面に表示されているキャラクターそれぞれについて、
ブラウザ上ページ巡回が始まります。~
6. 完了すると「ro_quest_all_characters.csv」というファイルがパソコンの
　「ダウンロード」フォルダに保存されます。
